## Shanway

Shanway is Aether's voice. Not its brain.

It runs on TinyLLaMA 1.5B -- a small local model that is only permitted to do one thing: formulate.

```
Aether pipeline verifies  ->  TinyLLaMA formulates  ->  Shanway speaks
```

**Why Shanway cannot hallucinate -- even though it is based on TinyLLaMA:**

TinyLLaMA has its own pre-training. It knows millions of texts. It could hallucinate.

With Shanway it cannot. Three reasons:

**1. Controlled input**
TinyLLaMA never sees raw web data or unverified sources. It receives exclusively what the complete Aether pipeline has classified as structurally verified and trustworthy through all its layers. What does not pass through the pipeline does not exist for TinyLLaMA.

**2. Watertight system prompt**
The prompt explicitly forbids any statement not present in the verified context. No speculation. No own knowledge. No additions. Output length equals context length -- never more than the context provides.

**3. Silence as the exit**
When the verified context is empty or no anchor is close enough, Shanway does not respond. It does not invent an answer to be polite. Silence is valid output. Silence is integrity.

TinyLLaMA is not a knowledge carrier here. It is a translator -- from verified structural patterns into human-readable language. Nothing more.

## File Register and File Keys

Every file analyzed by Aether receives a unique one-time key -- a combination of its structural signature and a cryptographic random component.

```
File analyzed
    |
    v
Unique filekey generated
    |
    v
File encrypted and stored
    |
    v
Key belongs to you alone
```

Three scientific consequences:

**Reproducibility** -- Anyone can verify whether a dataset is unchanged. Tampering breaks the key immediately.

**Provenance** -- When was this dataset created? Analyzed through which pipeline? Immutably provable.

**Comparison without transfer** -- Images, datasets, measurement series can be structurally compared without raw data leaving the device. Only signatures travel.

```
Your image (local)    ->  signature  -+
                                       +- comparison -> result
Remote image (local)  ->  signature  -+

No image has left the device.
```

Sharing is optional and revocable at any time. You decide who may see your files -- not once at upload, but permanently.

## Meta-Anchors and Emergence Levels

Aether does not have a fixed number of knowledge levels. The graph itself decides when a new level emerges.

```
Level 1 -- Base Anchors
  Measured directly from raw data
  Verified three times by independent users
  Concrete: one process, one image, one moment

Level 2 -- Consensus Anchors
  Emerge when base anchors from different domains
  show the same signature
  Computed locally, optionally shared

Level 3 -- Meta-Anchors
  Emerge when consensus anchors repeat
  Never predefined -- always locally emergent
  Never in Anchor Packs -- always unique

Level N -- Attractor
  The graph eventually converges on
  a few fundamental structural principles
  This is not a claim -- it is a measurable question
```

Anchor Packs contain only Level 1. Level 2 and above always emerge locally -- from the specific combination of data collected on this device by this user.

No two Aether instances have the same meta-anchor graph.

## Democratization -- Nobody Gets Left Behind

Modern AI requires high-performance servers, internet connectivity, expensive hardware. Those without access are excluded.

Aether inverts this.

A ten-year-old Windows machine in a village without reliable connectivity benefits just as much as a research server in a major city. Not as a promise -- as architecture.

Aether lies as a symbiont on top of the existing operating system. It recognizes which processes do the same work. Which services consume resources without measurable effect. And says -- always with confirmation:

> *"Three processes are doing the same thing. You can stop two of them. That saves 340 MB RAM and 12% CPU. Shall I?"*

No jargon required. No expert knowledge needed. No subscription. No cloud dependency. Linux fallback included.

Anchor Packs work offline. Meta-anchors emerge locally. Shanway runs on weak hardware. The swarm grows even without you -- but you grow with it once you join.

## Anchor Packs

Structural knowledge is small. Very small. An anchor describing one hour of climate data structurally is a few kilobytes -- not gigabytes.

This enables curated Anchor Packs -- verified structural collections that can be optionally downloaded. No raw data. No private content. Only structural knowledge that belongs to everyone.

With fast connectivity: automatic background preload.
With slow connectivity or offline: everything works anyway.

Packs accelerate the start. But meta-anchors always emerge locally. The swarm remains emergent.
